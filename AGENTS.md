# OpenSkitch

## Agent skills

### Issue tracker

Issues live in GitHub Issues on `shoemoney/OpenSkitch` (`gh` CLI); Forgejo is a push-only mirror with no issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one root `GLOSSARY.md` plus `docs/adr/`, created lazily. See `docs/agents/domain.md`.
